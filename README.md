# Taller 2 - Pokemon MVC - ITSQMET
Proyecto desarrollado en ASP.NET Core MVC como parte del Taller Práctico 2 de la asignatura Calidad de Software. La aplicación consume información desde PokeAPI y permite visualizar un listado de Pokémon, consultar sus detalles y navegar entre los diferentes registros mediante paginación.

## Funcionalidades
- Consumo de datos desde PokeAPI.
- Visualización de Pokémon mediante tarjetas.
- Consulta de nombre, número, altura y peso.
- Vista de detalles de cada Pokémon.
- Carrusel con imágenes frontal, posterior y versiones Shiny.
- Paginación del listado.
- Selección de la cantidad de Pokémon por página.
- Diseño personalizado mediante CSS.
- Efectos visuales al interactuar con las tarjetas e imágenes.

## Tecnologías utilizadas
- ASP.NET Core MVC.
- C#.
- HTML.
- CSS.
- Bootstrap.
- PokeAPI.
- Git y GitHub.
